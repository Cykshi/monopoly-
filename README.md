# Monopoly Online

A browser-based multiplayer board game inspired by classic Monopoly. Players can create rooms, join matches, purchase properties, participate in auctions, and trade assets in real time.

## Features

- Real-time multiplayer gameplay using Socket.IO
- Room creation and player joining
- Property purchases, rent, and upgrades
- Auctions and player-to-player trading
- Turn management, dice rolls, and jail mechanics
- Server-side validation of important game actions
- Responsive interface for desktop and mobile browsers

## Tech Stack

- **Frontend:** Next.js, React, TypeScript, Tailwind CSS
- **Backend:** Node.js, Express
- **Real-time communication:** Socket.IO
- **Deployment:** Vercel and Render

## Run Locally

```bash
git clone https://github.com/Cykshi/monopoly-.git
cd monopoly-
```

Install dependencies in the `backend` and `frontend` directories, configure the environment variables using the provided examples, and start both services in separate terminals.
